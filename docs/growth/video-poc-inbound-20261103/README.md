# AI動画解析・PoC受託開発インバウンド導線 — 実装・公開前検証

実装日：2026-11-03。対象：Cyber Knock `exorql/cyberknock`。

## 最重要成果

**有効なBtoB受託開発の問い合わせ → 商談 → 提案 → 有償PoC／開発受注**。集客量だけを目的としない。スポーツ向けアプリの導入相談と、映像AI・PoC受託の開発相談を同じ契約・商流として扱わない。

## 変更範囲

- `/ai-video-analysis`：AI動画解析・選手追跡・姿勢推定・PoC受託開発の専門LP。発注者の課題、技術検証の役割、成果物、導入条件、FAQ、既存フォームへのCTAとページ内フォーム。
- `/ai-video-analysis/soccer-player-tracking`：対象選手の指定、追跡候補、レビュー、区間出力の検証内容。技術経路と実AI精度の区別。
- `/ai-video-analysis/kyudo-motion-analysis`：一射の姿勢推定・軌跡・動作候補時刻の検証内容。正確な関節中心・正式な会の長さ・重心などの未評価を明記。
- トップのサービス導線、サイトヘッダー・フッター・スポーツDXの内部リンク、sitemap.xmlに追加。
- 既存問い合わせフォームを再利用。送信元は固定語 `video_poc` `soccer_poc` `kyudo_poc` に分離。Cloudflare Pages Functionで許可し、既存Slack宛先へ固定日本語ラベルで通知する設計。新しい外部宛先は追加しない。
- GA4カスタムイベントは従来の `cta_click`、`case_study_click`、`case_study_view`、`contact_form_*` を再利用し、3つの固定ページカテゴリを追加。メール・名前・本文・検索パラメータ等のPIIは送信しない。

## 技術検証の根拠と公開の境界

### サッカー

既存のローカル技術報告では、実動画入力から対象指定・追跡候補表示・レビュー・人手の承認に基づく区間出力までの経路を検証。一方、別の独立採点では本人追跡の取り違えやプレー候補の見落としがあり、自動抽出精度は合格していない。社内テスト件数をAI適合率・再現率と読み替えていない。

### 弓道

撮影済みの一射から、動作候補時刻・手首などの軌跡・一部の2D参考角度・姿勢推定の重畳表示を検証。欠測時は描画を控える。計測精度、正式な会の長さ、重心、他の射への外挿は未評価。技術QAの成功は測定精度の証明ではない。

### 実写・顧客情報の扱い

- 両技術ページのSVGは**新しく制作した工程説明図**であり、実AI結果のキャプチャではないことを図の直下に明記。
- 元実写・個人を識別する動画・顧客の名称／ロゴ・非公開UIのスクリーンショット・社内見積・会話・元ファイルパスはサイトへ配布しない。
- 元映像の権利や撮影者・被写体の公開許諾を確認できていないため、**実写動画デモの公開は保留**。このブロッカーをクリアしない限り実映像を含む静止画も公開しない。
- テスト動画と実結果の混同を防ぐ。顔や身体データを匿名化したと推測して許諾済み扱いしない。
- 専門LPと技術検証ノートは顧客の採用・商用精度の実績だとは記載しない。

## 既存機能の保護

- `/` および `/sports-dx` の主要見出し・問い合わせCTA・連絡先・検索メタデータは変更しない。関連内部リンクのみを追加。
- `/cases/ai-sports-trainer` は自社プロダクトの公開・運用実績のまま維持する。
- `/contact` のCloudflare Pages Functionと送信先を維持。新しいsourceラベルだけを追加。
- 価格・納期・導入成果は未確定のため載せない。受託をスポーツ領域だけに限定しない。
