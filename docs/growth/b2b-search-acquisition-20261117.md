# 法人向け検索流入の獲得：動画解析AIの発注意図に対応（2026-11-17）

## 目的
Cyber Knockの法人LP `/ai-development` に、AI開発を具体的に外注したい担当者からの自然検索流入を増やし、相談の機会をつくる。**流入・順位・CVRの改善は現時点で未検証**。

## 検索意図の役割分担

| 検索意図（需要数は未検証） | 対応するページ | 独自の提供価値 |
| --- | --- | --- |
| AI動画解析・動画解析システム 開発／依頼／受託 | `/insights/ai-video-analysis-development-request`（新規） | 解析処理の違い、入力条件、品質評価、開発依頼チェックリスト |
| AI動画解析 PoC 費用・見積 | `/insights/ai-video-analysis-poc-cost`（既存） | 見積の変動要因、PoCと本開発の費用区分 |
| AI PoC 開発・評価 | `/insights/ai-poc-process-evaluation`（既存） | PoCの目的、評価設計、Go/No-Go |
| AI開発会社 選び方・外注 | `/insights/ai-development-outsourcing-guide`（既存） | AI開発会社の比較、依頼内容の整理 |
| AIアプリ 受託開発・動画AI開発の相談 | `/ai-development`（既存） | 対応範囲、実装と継続運用の自社実績、相談窓口 |

需要数・順位・CVRの根拠は取得できていないため、検索語の実需を「多い」と断言しない。サービスLPの過剰なキーワード詰め込みや、同じ内容の量産ページは作らない。

## 今回の実装
- 新規発注ガイドを独立した静的・インデックス対象記事として作成
- ホームと法人LPのガイド一覧に自動追加、法人LPの動画解析対応領域に文脈付き内部リンク
- /insights 一覧を4記事対応へ更新し、新記事のcanonical・OG・Article構造化データ・サイトマップ追加
- 新記事の計測パスとガイドIDを固定allowlistに追加（個人情報・生URLは送らない）
- 既存の費用記事と発注ガイドの検索意図を区別。未公開PoCを実績扱いせず、精度や費用の保証をしない

## 公開後に確認する数字
1. 反映直後：本番HTMLのcanonical・内部リンク・sitemap・GA4読み込みと記事閲覧を確認
2. 7〜14日：Search Consoleで対象記事の検出・クロール・インデックス可否を確認（登録は保証されない）
3. 28日：新記事と既存3記事の検索表示回数・クリック・クエリ、/ai-development への流入経路、`insight_click` と `cta_click` を確認
4. 56日：新記事からの有効な法人相談数と、施策前の同期間・同対象との比較を行い、次に加筆するテーマを判断

## 現時点の計測制約
GSC Wizardは契約が有効でないためAPIアクセスできず、Search Console/GA4の実測ベースラインは取得できない。検索エンジンからの順位や流入は、PR作成時に増加を主張しない。GitHub Actionsの実行や本番マージ・デプロイはこの作業に含めない。
