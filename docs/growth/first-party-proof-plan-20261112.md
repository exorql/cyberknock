# Cyber Knock｜法人向け自社アプリ実績の公開・測定条件

作成：2026-11-12。対象：自社アプリ「AIスポーツトレーナー」のB2B転用実績。

## 今回の公開事実

- iOS/Android向けにAIスポーツトレーナーを自社開発・公開・運用している。
- /demos/ai-sports-trainer は、すでに公式サイトの開発事例で使用していた実際のアプリ画面3点を用いた閲覧型デモである。
- 画面は利用体験を示す証拠であり、解析精度・顧客の改善効果・受託実績・PoC合格率の証拠ではない。
- このページでは顧客動画のアップロード、リアルタイムAI推論、外部向け精度保証を行わない。
- 法人LP、事例ページ、動画解析の費用記事からデモへ導線を設け、CTAに専用の demo_click イベントを追加した。

## 実測数値の公開前に必要な一次資料

| 指標 | 確認する一次資料・計算基準 | 現時点 |
|---|---|---|
| 解析成功率 | 観測期間、モード、母数、successとfailureの定義、再試行・タイムアウトの扱い | 未検証・非掲載 |
| 処理時間 | 同じ期間と環境、p50/p95、動画の尺・解像度・端末とサーバー条件 | 未検証・非掲載 |
| 動作認識品質 | 権利処理済みの評価映像、正解ラベル、未検出・誤検出などの評価手順 | 未検証・非掲載 |
| 改善前後の効果 | 同一評価集合・同一採点ルールでのbefore/after・変更版の特定 | 未検証・非掲載 |
| モバイル運用品質 | クラッシュ・処理失敗の集計と対象端末・アプリ版・期間 | 未検証・非掲載 |

本事業の実績として顧客案件を持ち出さない。顧客の元動画・個人情報・契約先の非公開資料は、匿名化の妥当性と公開許可を確認しない限り掲載しない。

## B2B事業成果の効果測定

1. GSC：新デモのインデックス・表示・検索クエリ（サイト移行直後は未蓄積として扱う）
2. GA4：法人LP・費用記事・事例からの demo_click、デモの page_view
3. GA4：デモ上の cta_click、フォーム開始・送信成功
4. 営業台帳：実際の有効問い合わせ・商談・受注・粗利益（個人識別子のGA4への投入は禁止）
5. 2〜4週間の観察で「デモ閲覧後の相談があるか」を評価。ただしURL/セッションを連結する識別子がないため個別の受注帰属は推定しない。

## 数値根拠の追加作業

1. プライバシーに配慮した実サーバー集計または権利処理済みの再現用評価セットから、上記分母・分子・条件を取る。
2. 公開できる数字だけに実測期間、環境、対象と除外条件を併記する。
3. 個別競技や案件での結果を、全競技・あらゆる撮影条件での保証へ一般化しない。
