  - region "実運用で難しかったこと":
    - paragraph: 実運用の知見
    - heading "実運用で難しかったこと" [level=2]
    - paragraph: デモやプロトタイプではなく、実ユーザー環境で継続的に運用するからこそ直面した課題です。
    - generic: "01"
    - heading "AIに評価させすぎない" [level=3]
    - paragraph: 姿勢推定や映像から取得できる情報にも限界があるため、確認できない動作や身体状態を推測して評価しないよう設計しています。カメラアングルや画質の制約上、判断できない項目は「評価できない」と返す設計です。
    - generic: "02"
    - heading "入力動画のばらつき" [level=3]
    - paragraph: 撮影角度、カメラ距離、全身が映っているか、遮蔽、動作速度など、実ユーザーの動画には大きなばらつきがあります。これらは姿勢推定・動作解析の結果にも影響するため、実ユーザー動画を前提とした入力検証と例外処理の設計が必要でした。
    - generic: "03"
    - heading "競技ごとの評価軸" [level=3]
    - paragraph: 同じ関節角度や動作でも、競技・局面によって意味が異なります。共通の姿勢推定処理だけでは対応できないため、競技特性を考慮した評価設計が必要です。
    - generic: "04"
    - heading "年齢に応じたフィードバック" [level=3]
    - paragraph: 子ども向け・保護者向け・成人向けでは、適切な説明の粒度や言葉が変わります。同じ分析結果でも伝え方を調整する仕組みが必要でした。
    - generic: "05"
    - heading "AI出力の安定化" [level=3]
    - paragraph: JSON等の構造化出力、検証ロジック、異常値の処理、分析不能ケースのハンドリングなど、AI出力を安定してサービスに組み込むための処理が必要です。
    - generic: "06"
    - heading "コストと待ち時間" [level=3]
    - paragraph: 精度だけでなく、AI APIのコストや動画処理時間もプロダクトの品質に直結します。実運用の中でバランスを調整し続けています。
