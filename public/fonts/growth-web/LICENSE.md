Sources: https://github.com/google/fonts/tree/main/ofl — license text: https://openfontlicense.org
`manifest.json` lists the characters each subset covers; `tests/growth-web-lp.test.mjs` fails when a mincho heading uses a character that is not covered. Body text uses system Japanese fonts.
