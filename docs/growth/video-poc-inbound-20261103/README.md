# Cyber Knock｜AI動画解析・PoC受託開発の公開前記録

更新日：2026年11月3日。PR #4の最終公開候補についての仕様です。

## 最優先の成果

有効なBtoB開発相談 → 商談 → 提案 → 有償PoC・開発受注を増やす。AIスポーツトレーナーのアプリ導入相談と受託開発を別の商流として扱います。

## 公開する内容

- `/ai-video-analysis`：AI動画解析、姿勢推定、人物・動作の追跡、動画処理APIなどの技術的な対応相談の入口。具体的に実現できるかは撮影条件とPoCで判定する。
- 対象の業務課題、要件定義、PoC評価の進め方、想定成果物、FAQ、問い合わせフォームを提示する。
- 実績として示すのは**自社で開発・運用する「AIスポーツトレーナー」**のみ。リンク先は既存の`/cases/ai-sports-trainer`。
- サイト内のホーム、スポーツDX、ヘッダー・フッターから専門LPへ誘導。既存の自社アプリ導線や他のSEO資産は維持。
- Cloudflare Pages Functionの問い合わせ元は`video_poc`に固定し、既存のSlack宛先へ通知。新たなWebhook先は作成しない。
- GA4は、正規の測定IDがビルド時に設定されたときだけ読み込む。設定・本番受信は未確認。[設定手順](./GA4-SETUP.md)。

## 公開しない内容

- 契約前の個別案件に関する技術試験、業務要件、デモ映像、相手先の存在・名称・検証進捗。
- 顧客から公開承認を得ていない映像、写真、UI、結果、社内見積。
- 本番で実証していない精度、処理能力、固定価格、固定納期を保証する表現。

今回の修正では、提案段階の案件に関する個別ページ・カード・サイトマップ項目・検証用識別コード・公開スクリーンショットを取り下げました。未契約の案件情報を「技術検証」の名称で公開することも避けています。

## 品質検証と公開判断

- TypeScript、Nodeテスト、静的ビルド、ページURLと内部リンク、問い合わせ元、SEOメタデータ、実ブラウザの表示を確認。
- 自社アプリへのリンクは商用受託の導入実績を意味しないことを明記。
- 個別案件ページが生成されないことを、公開出力のディレクトリ検査でも確認する。
- 顧客へのメール、広告出稿、マージ、本番デプロイは本PRでは行わない。

結果の詳細は[QA-RESULTS.md](./QA-RESULTS.md)、公開後の事業効果は[MEASUREMENT.md](./MEASUREMENT.md)。
